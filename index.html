등속 = 속력이 일정 — 합속도 v의 길이는 늘 같지만 방향이 계속 바뀝니다. 그래서 vx·vy는 매 순간 변해요. 매 초 점 간격이 일정한 것은 같은 시간에 같은 거리(등속)라는 뜻입니다. 회색 화살표는 0.1초마다의 속도(vx·vy 성분과 합) — 합의 길이는 같고 방향만 도는 게 보입니다.
방향이 바뀜 = 속도가 바뀜 — 속력(빠르기)은 같아도 방향이 변하므로 속도는 변하는 중입니다. 그래서 등속원운동에도 가속도(중심 방향)가 있습니다.

🎨 색깔·법칙

물체 1 (질량 m1, 파랑)
물체 2 (질량 m2, 초록)
속도 — 길이 = 빠르기, 방향 = 운동 방향
운동량 보존 법칙: 외부 힘이 없으면 충돌 전후 전체 운동량의 합이 변하지 않습니다. 충돌 중 A·B가 주고받는 힘은 크기가 같고 방향이 반대(작용·반작용)여서, 서로 받은 충격량이 상쇄되기 때문입니다.
운동량은 방향이 있는 양이에요. 오른쪽 +, 왼쪽 − 로 부호까지 넣어 더해야 합니다.
운동량 보존 ≠ 운동에너지 보존! 운동량은 네 경우 모두 보존되지만 운동에너지는 달라요: ①② 탄성충돌은 운동에너지도 보존, ④ 합쳐짐(완전 비탄성)은 운동에너지가 줄어듭니다(열·소리·찌그러짐으로). ③ 갈라짐은 정지에서 움직이므로 운동에너지가 오히려 늘어요(내부 에너지 → 운동). 그래도 운동량 합은 늘 그대로.
충돌 후 정지(A) vs 다시 튕겨나옴(B) — 튕길 때 충격량이 더 크다

🎬 재생

👁 표시 항목

📊 충격량 = 운동량 변화 Δp (방향 포함)

A (정지): 운동량 변화
3mv → 0, Δp = −3mv ⟹ 충격량 크기 3mv
B (튕김): 운동량 변화
3mv → −mv, Δp = −4mv ⟹ 충격량 크기 4mv
부호 규약 (방향)
→ 오른쪽 +, ← 왼쪽 −
결론
튕긴 B가 더 큼 (4mv > 3mv)

🧠 핵심

충격량 = 운동량 변화 Δp (방향을 포함하는 벡터). 충격량의 방향 = 물체에 작용한 힘의 방향으로, 여기서는 둘 다 왼쪽(−)입니다. 운동량의 방향 = 속도의 방향.
왜 튕길 때 더 큰가? A는 3mv → 0 (변화 −3mv). B는 3mv → −mv(반대 방향)로 더 많이 바뀌어 변화가 −4mv. 그래서 충격량(=Δp)이 더 큽니다 (4mv > 3mv).
부호 규약: 직선상에서 한쪽을 +, 반대를 −로. 예) 2 kg이 +1 m/s면 운동량 +2 kg·m/s, −1 m/s면 −2 kg·m/s. 부호(−)는 그 양의 방향이 왼쪽이라는 뜻.
충격량 = 운동량 변화 Δp — 운동 방향이면 증가(가속), 반대면 감소(감속)

👉 충격량 방향

처음 운동량 p₀ = m·v₀ = 3 kg·m/s(오른쪽). 충격량을 같은 방향(+)으로 주면 운동량이 늘고, 반대(−)로 주면 줄어요. 반대 충격량이 p₀보다 크면 멈췄다가 반대로 움직입니다.

🎬 재생

👁 표시 항목

📊 p = p₀ + J (충격량 = 운동량 변화)

처음 운동량 p₀
3 kg·m/s (→)
충격량 J (방향)
+2 (운동 방향)
나중 운동량 p = p₀ + J
5 kg·m/s
결과
운동량 증가 (가속)

🧠 핵심

충격량 = 운동량 변화 (J = Δp = p − p₀). 방향을 포함하는 벡터라서, 꼬리-머리로 더합니다: p = p₀ + J.
운동 방향으로 충격량(+): 운동량이 그만큼 커집니다(가속). 반대 방향(−): 운동량이 줄어듭니다(감속). 반대 충격량이 처음 운동량보다 크면 0을 지나 음수가 되어 방향이 뒤집힙니다.
예) 공을 같은 방향으로 차면 더 빨라지고, 굴러오는 공을 막아 반대로 힘을 주면 느려지다 멈추거나 되돌아갑니다. 부호: 오른쪽 +, 왼쪽 −.
충격량 = 힘-시간 그래프 아래 넓이 — 잘게 쪼갠 막대를 이어 붙이면 곡선 아래 넓이가 됩니다

📐 힘의 모양

힘이 변하면 한 개의 직사각형으로는 넓이를 못 구합니다. 시간을 잘게 쪼개 보세요.

✂️ 잘게 쪼개기

슬라이더를 오른쪽으로 옮길수록 막대가 가늘어지고, 막대 윗부분이 곡선에 점점 달라붙습니다.

📏 평균 힘 = 같은 넓이 직사각형

곡선 아래 넓이를 그대로 둔 채 평평하게 펴면(튀어나온 부분이 빈 곳을 메움), 그 평평한 높이가 바로 평균 힘 4 N입니다. 넓이 = 평균힘 × 시간 = 16.

👁 표시 항목

📊 막대 넓이의 합 → 곡선 아래 넓이 (= 충격량)

막대 개수 n
4
막대 하나의 시간 폭 Δt = (시간)/n
1.00 s
막대 넓이의 합 = Σ (힘 × Δt)
16.50 N·s
곡선 아래 참넓이 (= 충격량)
16 N·s

🧠 핵심 — 미적분 없이 이해하기

충격량 = 힘-시간 그래프 아래 넓이. 힘이 일정하면 넓이는 그냥 직사각형 = 힘 × 시간 입니다(한 번에 끝).
힘이 변하면 한 직사각형으로 못 구합니다. 대신 시간을 아주 짧게 쪼개면 각 짧은 구간에서는 힘이 거의 일정 → 그 구간 넓이 ≈ (그 구간 힘) × Δt. 가는 막대 하나가 바로 그것입니다.
이 가는 막대들을 모두 이어 붙여 더하면 곡선 아래 넓이가 됩니다. 더 잘게 쪼갤수록 곡선과 막대 사이 빈틈이 사라져 참넓이와 같아집니다. (이것이 적분의 기본 생각: 잘게 쪼개 더하기.)
곡선 아래 넓이 = 평균 힘(4 N) × 시간(4 s) = 16 N·s. 변하는 힘도 평균을 쓰면 일정한 힘과 같은 넓이가 됩니다. (막대 높이는 '그 짧은 구간 한가운데의 힘'으로 잡았습니다.)
